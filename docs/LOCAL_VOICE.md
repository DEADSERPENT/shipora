# Local voice (English)

Voice is STT → agents (Ollama) → TTS. **Everything is local by default; no API key is needed.**

| Stage | Default | Model (pinned commit) | Output |
|---|---|---|---|
| STT | `faster_whisper` | `Systran/faster-whisper-small.en` (MIT) @ `d1d751a5f8271d482d14ca55d9e2deeebbae577f` | text |
| TTS | `kokoro` | `hexgrad/Kokoro-82M` (Apache-2.0) @ `f3ff3571791e39611d31c381e3a41a3af07b4987`, voice `af_heart` | 24 kHz mono WAV |

Alternatives: `STT_PROVIDER=onnx_local` (Whisper on ONNX, for PCs where CTranslate2 is blocked by OS policy), `TTS_PROVIDER=piper`
(needs a voice file in `local_models/piper/`). Hosted `openai` STT/TTS is opt-in only (`pip install openai==1.54.0`, set the provider
and `OPENAI_API_KEY`). A failing local model is **never** replaced by a hosted one: the voice call returns 422 and the log says what to fix.

## Install (Windows or Linux, Python 3.11)

```
cd backend-fastapi
pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu126   # CUDA build; skip for CPU-only
pip install -r requirements-local-voice.txt
```

Models download on first use into `local_models/` (git-ignored; never commit them). Set `VOICE_WARMUP=true` (default) to load them at
startup, so the first caller doesn't wait. Nothing in the system CUDA install is touched; the CUDA DLLs come from pip packages.

## Settings (all optional, see `.env.example`)

* `FASTER_WHISPER_DEVICE=auto|cpu|cuda` — load order: CUDA float16 → CUDA int8_float16 → CPU int8. Beam 3, VAD on, language `en`.
* `KOKORO_DEVICE=auto|cpu|cuda` — CUDA if available, CPU on any CUDA failure, including out-of-memory mid-run. `KOKORO_VOICE` picks the voice.
* `VOICE_STT_CONCURRENCY` / `VOICE_TTS_CONCURRENCY` (default 1) and `VOICE_*_TIMEOUT_SECONDS` (default 30): extra requests queue; a
  request that can't finish in time returns 422 instead of piling more models onto the GPU.
* On a 6 GB GPU shared with Ollama, set `KOKORO_DEVICE=cpu` if VRAM gets tight.

## Measured on this project's RTX 3060 Laptop (6 GB), Ryzen 7 6800HS, torch 2.7.1+cu126, ctranslate2 4.8

Single run of one ~6.4 s sentence generated by Kokoro and transcribed by Whisper; not a benchmark suite.

| | Result |
|---|---|
| Whisper small.en, GPU float16 | 0.66–0.75 s for 6.4 s audio (RTF ≈ 0.1); 0.4 s in the full pipeline |
| Kokoro, GPU | 0.21–0.27 s for 6.4 s audio (RTF ≈ 0.04) |
| Load time (warm disk cache) | Whisper ≈ 3 s, Kokoro ≈ 13 s |
| GPU memory, whole machine | Whisper 0.7 GB; + Kokoro 1.5 GB; + Ollama `qwen2.5:3b` (4096 ctx) ≈ 3.6 GB of 6 GB |
| End-to-end `/api/voice/chat`, LLM warm | STT 0.40 s + LLM 1.78 s + TTS 0.19 s = 2.4 s (`scripts/verify_sandwich.py`) |

**Not measured:** word error rate on clean vs noisy audio, peak RAM, tool-selection accuracy over a test set, behaviour under real
concurrent load. First-ever Ollama load took >30 s on this machine, so warm the LLM before judging latency.

## Verify

```
python -m pytest -q                              # fast tests (models faked)
RUN_REAL_VOICE=1 python -m pytest -q tests/test_local_voice_default.py -k real   # real models, real audio
python scripts/verify_sandwich.py                # STT → agents → TTS and /api/voice/chat, real providers
```
